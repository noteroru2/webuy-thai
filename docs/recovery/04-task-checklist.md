# รายการงานและเช็คลิสต์กู้คืนระบบ SEO (SEO Recovery Task Checklist)

รายการเช็คลิสต์ด้านล่างนี้ถูกออกแบบมาเพื่อให้นักพัฒนา หรือเครื่องมือเอไอช่วยพัฒนา (เช่น Cursor / Claude / Codex) สามารถดำเนินการแก้ไขโปรเจกต์ต่อได้ทันทีทีละขั้นตอนอย่างเป็นระบบและปลอดภัย:

---

## 🗹 Batch 1: Cleanup Indexability & Sitemap
*แก้ปัญหาเนื้อหาคุณภาพต่ำ ปิดดัชนีจุดที่ไม่เกี่ยวข้อง ปรับแต่งแผนผังเว็บไซต์*

- [ ] **1.1 คัดแยกบทความ Off-Topic ไปกักกัน (Quarantine) หรือคัดทิ้ง**
  - ค้นหาและคัดเลือกไฟล์ Markdown ใน [posts](file:///C:/Users/User/Desktop/project%20ทั้งหมด/webuy-thai/src/content/posts/) ที่มีคำจำพวก `รับซื้อเหล้า`, `รับซื้อไวน์`, `ตั๋วจำนำ`, `รับซื้อกระดาษ`, `รับจำนำ`
  - นำไฟล์เหล่านั้นย้ายออกจากโฟลเดอร์หลักไปไว้ที่ [quarantine](file:///C:/Users/User/Desktop/project%20ทั้งหมด/webuy-thai/src/content/quarantine/) เพื่อไม่ให้บิวด์ออกมาเป็หน้าเว็บจริง
- [ ] **1.2 กำหนดหน้าท้องถิ่นย่อยเป็น NOINDEX**
  - แก้ไขไฟล์ Markdown ของหน้าอำเภอย่อย (เช่น วารินชำราบ, เดชอุดม, ชุมแพ, ปากช่อง)
  - เพิ่มหรือแก้ไขค่า `noindex: true` ใน frontmatter ของหน้าเหล่านี้
- [ ] **1.3 ปรับฟังก์ชันส่งรหัส HTTP Status 410 (Gone)**
  - อัปเดตโครงสร้างเซิร์ฟเวอร์รันไทม์ หรือแก้ไข Middleware หรือไฟล์ [start.mjs](file:///C:/Users/User/Desktop/project%20ทั้งหมด/webuy-thai/scripts/start.mjs)
  - ตรวจจับพาธที่ลบออกไปและส่งคืนรหัส HTTP `410` ไปให้ Search Engine แทน `404` หรือ `301` เพื่อสั่งการลบอย่างรวดเร็ว
- [ ] **1.4 อัปเดตสคริปต์กรอง sitemap**
  - แก้ไข [generate-sitemaps.mjs](file:///C:/Users/User/Desktop/project%20ทั้งหมด/webuy-thai/scripts/generate-sitemaps.mjs)
  - ให้ระบบข้ามการนำลิงก์ที่มีคุณสมบัติ `noindex: true` หรือลิงก์ที่เป็นหน้าท้องถิ่นระดับอำเภอย่อยเข้าไปในระบบ sitemap-*.xml

## 🗹 Batch 2: Rewrite Core Pages
*ลบเนื้อหาล่อบอท เปลี่ยนสไตล์การเขียนคีย์เวิร์ดให้ดูเป็นธรรมชาติ (People-First)*

- [ ] **2.1 เอาข้อความสอน AI/Bot ในหน้าแรกออก**
  - เปิดไฟล์ [SeoProseSection.astro](file:///C:/Users/User/Desktop/project%20ทั้งหมด/webuy-thai/src/components/home/SeoProseSection.astro)
  - ลบส่วนบล็อกเนื้อหาทั้งหมดที่มีหัวข้ออ้างอิงถึง `Answer Engine (AEO)` และ `Generative AI Summary (GEO)`
  - เขียนอธิบายสั้นๆ ด้วยสไตล์เนื้อหาปกติสำหรับลูกค้าทั่วไป
- [ ] **2.2 นำข้อความ Claim-Heavy ออกจากหน้าเพจทำเงิน**
  - เปิดหน้ารายการสินค้าหลัก เช่น [รับซื้อโน๊ตบุ๊ค.astro](file:///C:/Users/User/Desktop/project%20ทั้งหมด/webuy-thai/src/pages/รับซื้อโน๊ตบุ๊ค.astro) และ [รับซื้อคอม.astro](file:///C:/Users/User/Desktop/project%20ทั้งหมด/webuy-thai/src/pages/รับซื้อคอม.astro)
  - ค้นหาและเปลี่ยนคำว่า `"ให้ราคาสูงที่สุด"`, `"ไม่กดราคาแน่นอน"`, `"สู้ทุกราคา"` ให้กลายเป็นถ้อยคำที่ระบุการให้คุณค่าจริง เช่น *"ประเมินราคาตามสเปกและสภาพการใช้งานจริงอย่างตรงไปตรงมา"*
- [ ] **2.3 เขียนโครงสร้างหัวข้อหน้ารับซื้อสินค้า Apple ให้ดูเป็นธรรมชาติ**
  - แก้ไขไฟล์ [รับซื้อแมคบุ๊ค.astro](file:///C:/Users/User/Desktop/project%20ทั้งหมด/webuy-thai/src/pages/รับซื้อแมคบุ๊ค.astro) เพื่อเปลี่ยนรูปประโยคสปินนิ่งเดิมให้เป็นย่อหน้าความรู้อ่านง่าย

## 🗹 Batch 3: Internal Link & Navigation Clean-up
*ขจัดสารปนเปื้อนในการลิงก์ภายใน*

- [ ] **3.1 คลีนลิงก์ของสินค้าที่ไม่เกี่ยวข้องออกจากระบบบทความ**
  - ตรวจสอบไฟล์ Markdown ที่ยังเก็บไว้ใช้ในระบบ
  - ค้นหาแถวข้อความหรือลิงก์ภายในที่อ้างถึงคำว่า `รับซื้อเหล้า` หรือคำนอกหมวดหมู่อื่นๆ แล้วทำการตัดย่อหน้าหรือลิงก์นั้นทิ้ง
- [ ] **3.2 จัดทำโครงสร้างลิงก์สนับสนุนหลัก (Hub-Spoke Internal Link)**
  - เพิ่มลิงก์ชี้กลับอย่างเหมาะสมจากหน้าจังหวัดหรือท้องถิ่น เช่น ชี้ลิงก์ข้อความ *"รับซื้อโน๊ตบุ๊ค"* กลับไปหาหน้าหลัก [รับซื้อโน๊ตบุ๊ค.astro](file:///C:/Users/User/Desktop/project%20ทั้งหมด/webuy-thai/src/pages/รับซื้อโน๊ตบุ๊ค.astro) เสมอ

## 🗹 Batch 4: Structured Data (Schema) Optimization
*ลดความขัดแย้งของข้อมูลโครงสร้าง ปรับแต่งระบบ Schema*

- [ ] **4.1 คัดแยกและจัดระเบียบสกีม่าบนหน้ารับซื้อหลัก**
  - เปิดไฟล์หน้า Astro ในโฟลเดอร์ [pages](file:///C:/Users/User/Desktop/project%20ทั้งหมด/webuy-thai/src/pages/)
  - ลดปริมาณสกีม่าซ้ำซ้อนในตัวแปร `articleJsonLd` ให้มีเฉพาะข้อมูลที่จำเป็นตรงประเด็น (เช่น คงเหลือไว้แค่ `FAQPage` + `Service` และตัด `Article` ออกหากเพจนั้นทำหน้าที่เป็นหน้าบริการขายสินค้าไม่ใช่บล็อกข่าวสาร)
- [ ] **4.2 แยกสกีม่า LocalBusiness ออกจากรากหลักของทุกหน้า**
  - แก้ไขไฟล์ [BaseLayout.astro](file:///C:/Users/User/Desktop/project%20ทั้งหมด/webuy-thai/src/layouts/BaseLayout.astro)
  - กำหนดเงื่อนไข (Conditional rendering) ไม่ให้ฝังโครงสร้าง `LocalBusiness` ลงไปในหน้านอกรอบ ให้รันสกีม่านี้เฉพาะในหน้าหลัก (`/`) และหน้าติดต่อเรา (`/contact/`) เท่านั้น

## 🗹 Batch 5: Mobile UX & Code Polish
*เพิ่มความรวดเร็วและเป็นมิตรกับผู้ใช้อุปกรณ์มือถือ*

- [ ] **5.1 ปรับหัวเรื่อง H1 ให้กระชับ**
  - แก้ไข H1 ในหน้าหลักทั้งหมดให้สั้นลงเพื่อแก้ปัญหาตกขอบบรรทัดบนมือถือ เช่น
    * จากเดิม: *"รับซื้อโน๊ตบุ๊คมือสอง ประเมินราคาฟรี จ่ายเงินสดทันที"*
    * เปลี่ยนเป็น: *"รับซื้อโน๊ตบุ๊คมือสอง ประเมินราคาด่วน"* (ความยาวไม่เกิน 35 ตัวอักษร)
- [ ] **5.2 เพิ่มระบบแบ่งหน้าหรือจัดกลุ่มรายชื่อจังหวัด**
  - แก้ไขไฟล์ [ProvincialGrid.astro](file:///C:/Users/User/Desktop/project%20ทั้งหมด/webuy-thai/src/components/money-pages/ProvincialGrid.astro)
  - เปลี่ยนพฤติกรรมการดึงลิงก์จากเดิมที่เรนเดอร์จังหวัดทั้งหมดพร้อมกัน ให้ใช้วิธีแสดงผลเฉพาะจังหวัดหลัก (เช่น อุบล, ขอนแก่น, โคราช, อุดร, กทม.) และมีปุ่มขยายกางดูจังหวัดอื่นๆ ตามความจำเป็นเพื่อลด DOM Size

## 🗹 Batch 6: Quality Assurance & Build Testing
*ตรวจสอบโค้ด บิวด์โปรเจกต์ และยืนยันความเรียบร้อยของ SEO*

- [ ] **6.1 รันคำสั่งตรวจสอบการทำงานของโค้ด**
  - เปิดเทอร์มินัลและสั่งรัน `npm run dev` หรือ `npm run build` เพื่อตรวจหาข้อผิดพลาดทางไวยากรณ์ (Syntax errors) หลังการแก้โครงสร้าง
- [ ] **6.2 ตรวจทานความสะอาดด้วย SEO Audit**
  - รันคำสั่งตรวจสอบ SEO ของระบบ `node scripts/seo-audit.mjs --source`
  - ตรวจเช็คว่าไม่มีหน้าใดติดปัญหา Canonical mismatch หรือ Description ซ้ำซ้อนหลงเหลืออยู่ในระบบ
- [ ] **6.3 ขอรับการจัดดัชนีใหม่บน Google Search Console**
  - ตรวจเช็คการอัปโหลด XML sitemap ที่สร้างใหม่และกดปุ่มขอจัดทำดัชนีใหม่ในระบบ GSC เพื่อเริ่มการกู้คืน
