# แผนผังการจัดการ URL และเทมเพลตหน้าเพจ (URL Action Map)

**โครงการ:** เรารับซื้อ.com V2 Recovery  
**กลยุทธ์:** แยกกลุ่มจัดการ URL เพื่อแก้ปัญหาดัชนีบวมและสแปมใน Google Search Console (GSC) โดยแบ่งออกเป็น 6 กลุ่มหลัก ดังนี้:

---

## 1. กลุ่ม KEEP (รักษาไว้และปรับปรุงทางเทคนิค)
*วัตถุประสงค์:* หน้าหลักที่มีความสำคัญสูงต่อธุรกิจและต้องรักษาตำแหน่งบนผลการค้นหา (Index) เอาไว้ พร้อมทำความสะอาดเนื้อหาให้มีคุณภาพสูงสุด

| ลำดับ | URL Path | ประเภท / ไฟล์ | คำแนะนำ |
| :--- | :--- | :--- | :--- |
| 1 | `/` | Static (`src/pages/index.astro`) | ลบส่วนแสดงผลสอนบอท AEO/GEO ที่มองเห็นด้วยตาออก |
| 2 | `/รับซื้อ/` | Static (`src/pages/รับซื้อ.astro`) | ปรับโครงสร้างข้อมูลลิงก์หมวดหมู่ให้ชัดเจน |
| 3 | `/รับซื้อโน๊ตบุ๊ค/` | Static (`src/pages/รับซื้อโน๊ตบุ๊ค.astro`) | เอาคีย์เวิร์ดอัดแน่นและคำสแปม (Claim-Heavy) ออก |
| 4 | `/รับซื้อคอม/` | Static (`src/pages/รับซื้อคอม.astro`) | ปรับปรุงคำอธิบายคุณค่าบริการ (Value Prop) ของร้าน |
| 5 | `/รับซื้อแมคบุ๊ค/` | Static (`src/pages/รับซื้อแมคบุ๊ค.astro`) | แก้ไขปัญหาชนกันกับบทความ `รับซื้อ-macbook` |
| 6 | `/รับซื้อไอโฟน/` | Static (`src/pages/รับซื้อไอโฟน.astro`) | รักษาโครงสร้างเดิม ปรับให้ People-First |
| 7 | `/รับซื้อไอแพด/` | Static (`src/pages/รับซื้อไอแพด.astro`) | รักษาโครงสร้างเดิม ปรับปรุงราคาให้ทันสมัย |
| 8 | `/รับซื้อกล้อง/` | Static (`src/pages/รับซื้อกล้อง.astro`) | รักษาโครงสร้างเดิม |
| 9 | `/พื้นที่ให้บริการ/` | Static (`src/pages/พื้นที่ให้บริการ.astro`) | ลบจุดที่ระบุสถานที่ซ้ำซ้อนระดับอำเภอ |
| 10 | `/รับซื้อโน๊ตบุ๊ค-อุบลราชธานี-คู่มือ/` | Static Astro Page | หน้าคู่มือเฉพาะพื้นที่ คุณภาพสูง ให้เปิด Index ไว้ |
| 11 | `/รับซื้อไอโฟน-อุบลราชธานี-คู่มือ/` | Static Astro Page | หน้าคู่มือเฉพาะพื้นที่ คุณภาพสูง ให้เปิด Index ไว้ |
| 12 | `/รับซื้อไอโฟน-ขอนแก่น-คู่มือ/` | Static Astro Page | หน้าคู่มือเฉพาะพื้นที่ คุณภาพสูง ให้เปิด Index ไว้ |
| 13 | `/รับซื้อโน๊ตบุ๊ค-โคราช/` | Static Astro Page | หน้าหลักจังหวัดโคราช (ลบไฟล์ชนกันใน Markdown ออก) |
| 14 | `/รับซื้อไอโฟน-อุดรธานี/` | Static Astro Page | หน้าหลักจังหวัดอุดรธานี |

## 2. กลุ่ม REWRITE (เขียนเนื้อหาใหม่และเปิด Index)
*วัตถุประสงค์:* หน้าท้องถิ่นหลักที่มีคุณค่าในเชิงพื้นที่ (Geographical Reach) แต่ใช้เนื้อหาเดิมที่เป็นเทมเพลตซ้ำซ้อน ต้องเขียนใหม่แบบ 100% Unique ให้มีข้อมูลพิกัดสถานที่จริง (Landmarks) ร้านพันธมิตร และวิธีการจัดส่งเฉพาะจังหวัดจริง

| URL Group | จำนวนเพจ | ตัวอย่าง URL | คำแนะนำ |
| :--- | :--- | :--- | :--- |
| **ไอโฟนระดับจังหวัดหลัก** | 4 เพจ | `/รับซื้อไอโฟน-ขอนแก่น/`<br>`/รับซื้อไอโฟน-โคราช/`<br>`/รับซื้อไอโฟน-อุดรธานี/`<br>`/รับซื้อไอโฟน-อุบล/` | เขียนด้วยข้อมูลพื้นที่จริง ห้ามใช้สปินข้อความคีย์เวิร์ดเดิม |
| **โน๊ตบุ๊คระดับจังหวัดหลัก** | 4 เพจ | `/รับซื้อโน๊ตบุ๊ค-ขอนแก่น/`<br>`/รับซื้อโน๊ตบุ๊ค-อุดรธานี/`<br>`/รับซื้อโน๊ตบุ๊ค-อุบล/` | เขียนใหม่ให้มีรายละเอียดแคมปัส มหาวิทยาลัย หรือห้างนัดรับจริง |
| **แมคบุ๊คระดับจังหวัดหลัก** | 4 เพจ | `/รับซื้อแมคบุ๊ค-ขอนแก่น/`<br>`/รับซื้อแมคบุ๊ค-อุดรธานี/`<br>`/รับซื้อแมคบุ๊ค-โคราช/`<br>`/รับซื้อแมคบุ๊ค-อุบล/` | ปรับเนื้อหาเรื่องการเช็กสถานะ Activation Lock และรอบแบตเตอรี่ |

## 3. กลุ่ม NOINDEX (คัดกรองออกจากดัชนีแต่เก็บหน้าเว็บไว้)
*วัตถุประสงค์:* หน้าเพจท้องถิ่นระดับอำเภอย่อย หรือหน้าย่อยสเปกสินค้าที่มีเนื้อหาเบาบาง (Thin Content) ซึ่งถูกสร้างขึ้นแบบ Mass Programmatic เพื่อป้องกันงบประมาณการคราวด์ (Crawl Budget) เสียเปล่า

| URL Group | จำนวนเพจ | ตัวอย่าง URL | คำแนะนำ |
| :--- | :--- | :--- | :--- |
| **หน้าอำเภอย่อยภาคอีสาน** | 450+ เพจ | `/รับซื้อวารินชำราบ/`<br>`/รับซื้อเดชอุดม/`<br>`/รับซื้อบ้านไผ่/`<br>`/รับซื้อชุมแพ/`<br>`/รับซื้อปากช่อง/`<br>`/รับซื้อโนนสูง/` | ตั้งค่า `noindex: true` ใน Frontmatter ย้ายเข้ากลุ่มปิดดัชนีอัตโนมัติ |
| **หน้าคอมพิวเตอร์ระดับเขตกทม.** | 50+ เพจ | `/รับซื้อคอม-พระนคร/`<br>`/รับซื้อคอม-ดุสิต/`<br>`/รับซื้อคอม-หนองจอก/`<br>`/รับซื้อคอม-บางรัก/` | Canonical ไปยัง `/รับซื้อคอม/` และตั้ง `noindex: true` เพื่อลดความซ้ำซ้อน |
| **หน้ารุ่นย่อย/อุปกรณ์เสริม** | 30+ เพจ | `/รับซื้อ-harddisk/`<br>`/รับซื้อฮาร์ดดิส/`<br>`/รับซื้อ-apple-watch-series-8-อุบล/`<br>`/รับซื้อ-apple-watch-series-7-อุบล/` | ปิดดัชนี (Noindex) เพื่อรักษาอำนาจให้หน้ารับซื้อสินค้าหลัก |

## 4. กลุ่ม 301 REDIRECT (เปลี่ยนเส้นทางแบบถาวร)
*วัตถุประสงค์:* จัดการหน้า URL ที่สะกดผิด หางขาด หรือ URL ภาษาอังกฤษที่มาชนกับหน้าภาษาไทยหลัก ให้ส่งผู้ใช้และบอทไปยังหน้าปลายทางที่ถูกต้องทันที

| ลำดับ | Source URL (สะกดผิด/ชนกัน) | Target URL (ปลายทางที่ถูกต้อง) | เหตุผล |
| :--- | :--- | :--- | :--- |
| 1 | `/รับซื้อ-macbook/` | `/รับซื้อแมคบุ๊ค/` | แก้ปัญหา Intent Cannibalization และ Slug ภาษาอังกฤษชนภาษาไทย |
| 2 | `/ติดต่อเรา/` | `/contact/` | เชื่อมโยง URL ภาษาไทยเข้ากับระบบหน้า Astro จริง |
| 3 | `/รับซื้อโน๊ตบุ๊ค-ศรีสะเก/` | `/รับซื้อโน๊ตบุ๊ค/` (หรือศรีสะเกษฉบับเต็ม) | แก้ปัญหา URL หางขาด สะกดผิด |
| 4 | `/รับซื้อคอมพิวเตอร์-ภูเก/` | `/รับซื้อคอม/` (หรือภูเก็ตฉบับเต็ม) | แก้ปัญหา URL หางขาด สะกดผิด |
| 5 | `/รับซื้อกล้องมือสอง-บุรี/` | `/รับซื้อกล้อง/` (หรือบุรีรัมย์ฉบับเต็ม) | แก้ปัญหา URL หางขาด สะกดผิด |
| 6 | `/รับซื้อ-macbook-จังหวัดกาฬสินธ/` | `/รับซื้อแมคบุ๊ค/` (หรือกาฬสินธุ์ฉบับเต็ม) | แก้ปัญหา URL หางขาด สะกดผิด |

## 5. กลุ่ม 410 GONE (แจ้งกูเกิลว่าหน้านี้ถูกลบอย่างถาวร)
*วัตถุประสงค์:* กำจัดหน้าเพจสแปมและหน้านอกเหนือหมวดหมู่ไอที (Off-Topic) ออกจากสารบบของกูเกิลอย่างเร็วที่สุด การส่ง HTTP Status Code 410 จะทำให้บอทนำหน้าออกจาก Index เร็วกว่ารหัส 404

| URL Group | ตัวอย่างคีย์เวิร์ดที่ต้องทำ 410 | ประเภทไฟล์ | คำแนะนำ |
| :--- | :--- | :--- | :--- |
| **รับซื้อแอลกอฮอล์** | `/รับซื้อเหล้า-.../`<br>`/รับซื้อไวน์-.../`<br>`/รับซื้อเบียร์-.../` | โพสต์ทั้งหมดที่เข้าเกณฑ์นี้ใน `posts/` | ลบไฟล์ Markdown ออกจากระบบ และส่งรหัส 410 ทันทีผ่านระบบ Redirect หรือ Middleware Server |
| **สแปมตั๋วจำนำ** | `/รับซื้อตั๋วจำนำ-.../`<br>`/รับจำนำ-.../` | โพสต์ทั้งหมดที่เข้าเกณฑ์นี้ใน `posts/` | ลบไฟล์และส่งรหัส 410 เพื่อล้างฐานข้อมูลสปินนิ่งทางการเงิน |
| **ของปั่นนอกหมวด** | `/รับซื้อกระดาษ/`<br>`/รับซื้อเหรียญญี่ปุ่น/` | โพสต์ทั้งหมดที่เข้าเกณฑ์นี้ใน `posts/` | ลบไฟล์และส่งรหัส 410 เพื่อกู้ความสะอาดด้าน Topical Authority คืนมา |

## 6. กลุ่ม NEEDS MANUAL REVIEW (ต้องพิจารณารายตัว)
*วัตถุประสงค์:* หน้าเฉพาะกลุ่มที่มีความก้ำกึ่งเรื่องมูลค่าและสถิติคราวด์ จำเป็นต้องติดตั้งระบบติดตามดู Conversion หรือตรวจ GSC คลิกผ่านจริงในอดีตก่อนดำเนินการขั้นถัดไป

* **`/รับซื้อคอมประกอบ/`:** มีเนื้อหาแยกออกมาจากหน้ารับซื้อคอมพิวเตอร์หลัก เนื้อหาค่อนข้างสั้น มีความเสี่ยงซ้ำซ้อนกับหน้ารับซื้อคอมพิวเตอร์ทั่วไป แต่มีกลุ่มลูกค้าเฉพาะ
* **`/รับซื้อสมาร์ทโฟน-android/`:** หน้านี้เปิด Index ไว้ แต่มีเนื้อหาค่อนข้างกว้างและบางจุดมีสเปกของรุ่นที่ล้าสมัยไปแล้ว
* **`/รับซื้อ-server/` และ `/รับซื้อ-ups/`:** เจาะกลุ่มลูกค้าบริษัท/สำนักงาน ควรพิจารณาว่าจะรวม (Consolidate) เข้ากับหน้า `/รับซื้อคอม/` หรือคงอยู่เป็นหน้าย่อยสำหรับทำ SEO ระดับ B2B
