**รับซื้อ SSD มือสอง** ครอบคลุมทุก Interface และทุกขนาด ตั้งแต่ SSD ทั่วไปสำหรับโน๊ตบุ๊คและ PC ไปจนถึง Enterprise SSD สำหรับ Server

## Interface ที่รับ

- **SATA 2.5"** สำหรับโน๊ตบุ๊คและ PC รุ่นเก่า
- **M.2 SATA** สำหรับเครื่องรุ่นกลาง
- **M.2 NVMe (PCIe)** สำหรับเครื่องรุ่นใหม่
- **PCIe Add-in Card** สำหรับ Workstation

## ยี่ห้อที่รับบ่อย

Samsung, WD (Western Digital), Kingston, SanDisk, Crucial, ADATA, XPG, Corsair, Seagate, Intel, Micron, Toshiba, Kioxia, Transcend, Apacer, Lexar, SK Hynix

## ปัจจัยที่มีผลกับราคา

- ความจุ (ยิ่งใหญ่ยิ่งดี)
- ยี่ห้อและรุ่น (Samsung EVO/PRO ราคาสูงกว่า)
- จำนวน TBW ที่เขียนไปแล้ว (SMART data)
- Interface (NVMe > SATA)
- สภาพโดยรวม
