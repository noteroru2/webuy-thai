**รับซื้อ UPS มือสอง** ครอบคลุมทุกยี่ห้อและทุกขนาด ตั้งแต่ UPS ตั้งโต๊ะขนาดเล็กไปจนถึง UPS Rack ระดับ Data Center WE BUY รับประเมินทุกกรณี

## UPS ที่รับซื้อบ่อย

| ยี่ห้อ | รุ่นที่พบบ่อย |
|---|---|
| APC | Smart-UPS, Back-UPS, Symmetra |
| CyberPower | CP, PR series |
| Eaton | 5P, 9PX, 93PS |
| Schneider / APC | Galaxy VX, Easy UPS |
| Syndome | ทุกรุ่น |
| Leonics | ทุกรุ่น |

## UPS แบบไหนที่ยังมีมูลค่าสูง

- UPS True Online (Double Conversion) ราคามักสูงกว่า Line-interactive
- UPS ขนาดใหญ่ 3kVA ขึ้นไป
- UPS Rack ที่ยังใช้งานได้
- UPS ที่เปลี่ยนแบตเตอรี่ใหม่แล้ว

## UPS เสียหรือแบตหมดยังรับไหม

รับได้ ถ้าตัวเครื่องยังสมบูรณ์แต่แบตหมด ประเมินต่ำกว่าปกติตามต้นทุนแบตที่ต้องเปลี่ยน ส่งรุ่นและอาการมาก่อนครับ
