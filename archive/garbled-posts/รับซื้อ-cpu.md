**รับซื้อ CPU มือสอง** ครอบคลุม Intel และ AMD ทุกรุ่น ทั้งสำหรับ PC ทั่วไปและ Workstation/Server

## CPU ที่รับบ่อย

### Intel
- Core i3, i5, i7, i9 ทุกรุ่น
- Xeon E3, E5, Gold, Platinum สำหรับ Server

### AMD
- Ryzen 3, 5, 7, 9 ทุกรุ่น
- Threadripper สำหรับ Workstation
- EPYC สำหรับ Server

## ปัจจัยที่มีผลกับราคา

- รุ่นและ Generation (ยิ่งใหม่ยิ่งดี)
- Core/Thread จำนวน
- TDP และ Cache
- สภาพขา Pin (Intel) หรือ Socket (AMD)
