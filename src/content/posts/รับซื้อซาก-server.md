**รับซื้อซาก Server** หมายถึง Server ที่ใช้งานไม่ได้แล้ว หรือชำรุดจนไม่คุ้มซ่อม แต่ยังมีชิ้นส่วนที่มีมูลค่าเหลืออยู่

## ซาก Server มีมูลค่าอย่างไร

- **CPU** (Xeon, EPYC) ยังมีตลาดอะไหล่สูง
- **RAM ECC** ความจุสูง ยังขายต่อได้
- **HDD SAS/SATA** ที่ยังสมบูรณ์
- **Power Supply** ของแบรนด์ Server ราคาสูง
- **Chassis/โครงเครื่อง** บางรุ่นยังมีค่า
- **PCIe Card** ต่าง ๆ เช่น HBA, NIC, RAID Card
