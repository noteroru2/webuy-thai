**คำตอบสั้น:** โน๊ตบุ๊คเปิดไม่ติด**อาจขายได้**หากยังมีมูลค่าชิ้นส่วน (CPU, RAM, SSD, การ์ดจอ) หรือซ่อมได้ — ราคาขึ้นกับสาเหตุ สเปก และความซื่อสัตย์ในการแจ้งอาการ

## ขายได้ไหม

ไม่ใช่ทุกเครื่องที่เปิดไม่ติดจะเหลือแค่ขยะ — โน๊ตบุ๊คสเปกดีหรือเกมมิ่งอาจยังมีผู้รับซื้อเพื่อนำ SSD/RAM หรือซ่อม

แต่ถ้าไม่ทราบสเปกเลยและตรวจไม่ได้ อาจประเมินยาก

## กรณีที่ยังรับซื้อได้

- แบตหมดจริง ชาร์จแล้วติด
- จอเสียแต่เครื่องติด (มีสเปกชัด)
- สเปกเกมมิ่ง/ทำงานที่ตลาดต้องการ
- เปิดได้เข้า BIOS แต่เข้า Windows ไม่ได้
- ไม่ติดบัญชี (Microsoft/BIOS password แจ้งตรง)

[รับซื้อโน๊ตบุ๊ค](/รับซื้อโน๊ตบุ๊ค/)

## กรณีที่ต้องตรวจเพิ่ม

- โดนน้ำ / กลิ่นไหม้
- เปิดไม่ติดหลังตกแรง
- ไม่มีสติกเกอร์สเปกและจำรุ่นไม่ได้
- มีรหัส BIOS ลืม
- แบตบวม

## กรณีที่ไม่รับซื้อหรือเสี่ยง

- เปิดไม่ติด ไม่ทราบสเปก ตรวจไม่ได้เลย
- เครื่องผิดกฎหมายหรือที่มาไม่ชัด
- ความเสียหายรุนแรงทั้งเครื่อง
- ติดล็อกบัญชีที่ปลดไม่ได้ (บางรุ่น)

## ปัจจัยที่มีผลต่อราคา

- CPU / GPU / RAM / SSD
- สาเหตุที่คาด (จอ vs บอร์ด vs แบต)
- แบรนด์รุ่น
- สภาพตัวเครื่อง
- อุปกรณ์ครบ
