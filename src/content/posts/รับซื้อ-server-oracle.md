**รับซื้อ Server Oracle** ทุกรุ่น ได้แก่ SPARC T-series, x86 Server และทุกรุ่น

Oracle SPARC Server มีตลาดเฉพาะ ราคาขึ้นกับรุ่น CPU SPARC และ Memory ที่ยังทำงานได้

## ข้อมูลที่ควรส่งก่อนประเมิน

- รุ่นเครื่องเต็ม เช่น SPARC T-series
- CPU รุ่นและจำนวน Socket
- RAM ความจุรวมและประเภท
- Storage จำนวนและขนาด
- สภาพโดยรวม ใช้งานได้หรือมีปัญหาอะไร
- รูปถ่าย Label หลังเครื่องหรือหน้า Bezel

## ปัจจัยที่มีผลกับราคา

- สเปก CPU และ RAM เป็นหลัก
- รุ่น Generation (ยิ่งใหม่ยิ่งดี)
- ครบชุดหรือไม่ (Rail Kit, Bezel, สาย Power)
- สภาพและอายุการใช้งาน
