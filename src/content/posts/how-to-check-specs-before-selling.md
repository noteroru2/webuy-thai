การรู้สเปกที่ถูกต้องของเครื่องเป็นหัวใจสำคัญในการตีราคามือสอง เพราะถ้าคุณแจ้งเพียง "Intel Core i7" โดยไม่บอกเจนเนอเรชัน หรือบอกแค่ "MacBook Pro" โดยไม่บอกปีและชิป ราคาประเมินอาจคลาดเคลื่อนไปหลายพันบาท บทความนี้จะสอนวิธีเช็กสเปกอย่างละเอียด เพื่อให้คุณได้ราคาที่ดีที่สุดและยุติธรรมที่สุด

## วิธีเช็กสเปกบน Windows (โน้ตบุ๊กทั่วไป, PC)

### 1. ใช้ System Information (ครบจบในหน้าเดียว)
วิธีที่ง่ายและให้ข้อมูลครบถ้วนที่สุดคือการใช้ System Information:
1. กดปุ่ม `Windows + R` บนคีย์บอร์ด
2. พิมพ์ `msinfo32` แล้วกด Enter
3. หน้าต่าง System Information จะเปิดขึ้นมา สิ่งที่คุณต้องดูคือ:
   - **System Model:** รุ่นของเครื่อง (เช่น IdeaPad 5 15IAL7)
   - **Processor:** รุ่น CPU เต็ม (เช่น 12th Gen Intel(R) Core(TM) i5-1235U)
   - **Installed Physical Memory (RAM):** ขนาดแรม (เช่น 16.0 GB)

*แนะนำให้จับภาพหน้าจอ (Screenshot) หน้านี้ส่งให้ร้านรับซื้อได้เลย*

### 2. เช็กการ์ดจอ (GPU)
ถ้าโน้ตบุ๊กของคุณมีการ์ดจอแยก (มักพบในรุ่นเกมมิ่งหรือทำงานกราฟิก):
1. ในหน้าหน้าต่างเดิม (msinfo32) ให้กดขยายแท็บ **Components** ทางซ้ายมือ
2. เลือก **Display**
3. ดูที่ **Name** จะเห็นชื่อการ์ดจอ เช่น NVIDIA GeForce RTX 5050 Laptop GPU

### 3. เช็กพื้นที่เก็บข้อมูล (Storage)
1. เปิด **This PC** (หรือ My Computer)
2. ดูที่ไดรฟ์ C: และไดรฟ์อื่นๆ ว่ามีพื้นที่รวมประมาณเท่าไหร่ (เช่น 237 GB = สตอเรจขนาด 256GB, 476 GB = สตอเรจขนาด 512GB)

## วิธีเช็กสเปกบน macOS (MacBook, iMac, Mac mini)

แอปเปิลออกแบบมาให้ดูข้อมูลง่ายมากในที่เดียว:

1. คลิกที่สัญลักษณ์ **Apple ()** มุมซ้ายบนสุดของหน้าจอ
2. เลือก **About This Mac** (เกี่ยวกับ Mac เครื่องนี้)
3. คุณจะเห็นข้อมูลสำคัญทั้งหมดทันที:
   - **รุ่นและปี:** เช่น MacBook Pro (13-inch, M1, 2020)
   - **ชิป (Chip / Processor):** เช่น Apple M1 หรือ 2.0 GHz Quad-Core Intel Core i5
   - **หน่วยความจำ (Memory):** เช่น 8 GB หรือ 16 GB
   - **หมายเลขประจำเครื่อง (Serial Number):** สามารถใช้เช็กประกันหรือข้อมูลละเอียดได้
4. **เช็กพื้นที่เก็บข้อมูล:** ให้คลิกปุ่ม **More Info...** (หรือแท็บ Storage ใน macOS รุ่นเก่า) แล้วเลื่อนลงไปดูที่หัวข้อ Storage

*เช่นเคย การจับภาพหน้าจอ About This Mac ส่งมาประเมินราคาจะเร็วที่สุด*

## สรุปข้อมูลที่ต้องส่งให้ร้านรับซื้อ

เพื่อให้การตีราคาเป็นไปอย่างรวดเร็วและแม่นยำ กรุณาเตรียมข้อมูล 4 อย่างนี้:
1. **รูปถ่ายสเปกเครื่อง:** (msinfo32 หรือ About This Mac)
2. **รูปถ่ายตัวเครื่องรอบด้าน:** หน้าจอ พอร์ตเชื่อมต่อ ด้านหลัง และรอยตำหนิ (ถ้ามี)
3. **สภาพแบตเตอรี่:** หากใช้งานได้ปกติหรือเสื่อมแล้ว
4. **อุปกรณ์ที่มาด้วย:** มีกล่อง สายชาร์จแท้ หรือใบเสร็จหรือไม่

ยิ่งข้อมูลละเอียด โอกาสได้ราคาที่ถูกใจและจบงานไวก็ยิ่งสูงขึ้นครับ!
