อยากขายมือถือ โน๊ตบุ๊ค หรือแท็บเล็ต แต่ไม่รู้ว่าเครื่องตัวเองจัดอยู่ใน "สภาพไหน" (เกรด A, B, หรือ C)? วันนี้ WE BUY มีเช็กลิสต์ **Self-Evaluation (ประเมินด้วยตนเอง)** ง่ายๆ 5 ข้อ ให้คุณลองทำก่อนทักหาร้านรับซื้อ เพื่อให้คุณรู้ทันและต่อรองราคาได้อย่างมั่นใจครับ

## 1. เช็ค "รอยภายนอก" แบบจับผิด (Cosmetic Check)
อย่าเพิ่งคิดว่าเครื่องใส่เคสมาตลอดแล้วจะไม่มีรอย! ฝุ่นที่เข้าไประหว่างเคสกับตัวเครื่องมักจะสร้าง "รอยขนแมว" และ "รอยกัดขอบ" ได้
* **หน้าจอ:** ปิดหน้าจอแล้วใช้ไฟฉายจากมือถืออีกเครื่องส่องดู มีรอยขนแมว หรือรอยแตกร้าวลึกหรือไม่
* **บอดี้ / เฟรม:** เช็คขอบมุมทั้ง 4 ด้าน มีรอยตกกระแทก (บุบ) รอยลอก หรือสีถลอกหรือไม่ 
* **เกรดที่ได้:** ถ้ารอยน้อยมองแทบไม่เห็น = เกรด A / รอยขนแมวทั่วไป = เกรด B / รอยตกกระแทกชัดเจน = เกรด C

## 2. เช็ค "สุขภาพแบตเตอรี่" (Battery Health)
แบตเตอรี่คือปัจจัยหักราคาอันดับ 1
* **iPhone / iPad:** เข้า Settings > Battery > <a href="/รับซื้อไอโฟน/">Battery Health</a> 
* **MacBook:** กด Option ค้าง > System Information > Power > ดู <a href="/รับซื้อแมคบุ๊ค/">Cycle Count</a>
* **เกรดที่ได้:** สุขภาพแบต 85-100% = ราคาเต็ม / 80-84% = โดนหักนิดหน่อย / ต่ำกว่า 80% หรือขึ้น Service = โดนหักค่าเปลี่ยนแบต

## 3. เช็ค "จุดกำเนิดเสียงและภาพ" (Audio & Display)
* **หน้าจอ:** เปิดภาพพื้นหลัง "สีขาวล้วน" และ "สีดำล้วน" ในห้องมืด ดูว่ามีจุดสีแปลกๆ (Dead Pixel) เส้นพาดจอ หรือแสงรั่ว (Light Bleed) ไหม
* **ลำโพงและไมค์:** เปิดคลิป YouTube เร่งเสียงให้สุด ฟังว่าเสียงลำโพง "แตก" ไหม ลองอัดเสียงตัวเองพูดแล้วเปิดฟังว่าไมค์ชัดเจนดีไหม

## 4. เช็ค "พอร์ตและการเชื่อมต่อ" (Ports & Connectivity)
จุดที่คนมักมองข้ามแต่ร้านรับซื้อตรวจทุกครั้ง:
* ลองเสียบสายชาร์จ ขยับสายเบาๆ ไฟชาร์จต้องไม่หลุด (ถ้าหลุดแปลว่าพอร์ตหลวม)
* ลองต่อ Wi-Fi และ Bluetooth ว่าหาสัญญาณเจอปกติและเชื่อมต่อได้เร็ว

## 5. เช็ค "กลไกเฉพาะรุ่น" (Specific Features)
* **iPhone / iPad:** ลองสแกนหน้า Face ID หรือ Touch ID ว่าทำงานรวดเร็วปกติไหม ลองสลับสวิตช์เปิด/ปิดเสียงด้านข้าง
* **MacBook / Notebook:** เปิดเว็บ Keyboard Tester กดให้ครบทุกตัวอักษร ลองขยับพับหน้าจอขึ้นลง (Hinge) ต้องไม่หลวมหรือมีเสียงดังก๊อบแก๊บ
