**คำตอบสั้น:** คอมเกมมิ่งมือสอง**ไม่มีราคาเดียว** — ขึ้นอยู่กับรุ่นย่อย ความจุ สภาพ อุปกรณ์ ประกัน และราคาตลาด ณ วันที่ประเมิน โดย **CPU + การ์ดจอ** มีผลมากที่สุด

## ราคาขึ้นอยู่กับอะไร

คอมเกมมิ่งดูสเปกหลัก: CPU, GPU, RAM, SSD, PSU รุ่น และสภาพการ์ดจอ (เคยขุด/อาการ artifact หรือไม่)

เคสและ RGB มีผ่านน้อยกว่าชิ้นหลัก แต่เครื่องโดนน้ำหรือเปิดไม่ติดจะประเมินต่างมาก — [รับซื้อคอม](/รับซื้อคอม/) | [ราคากลางรับซื้อ](/ราคากลางรับซื้อ/)

## ปัจจัยที่ทำให้ขายได้ราคาดี

- การ์ดจอรุ่นที่ตลาดยังต้องการ
- CPU คู่กับ GPU สมดุล ไม่ bottleneck หนัก
- RAM 16GB+ SSD ระบบลง Windows ได้
- PSU วัตต์พอ แบรนด์น่าเชื่อถือ
- เปิดติด ทดสอบเกม/ benchmark ผ่าน
- ภายในเคสสะอาด ไม่โดนน้ำ
- ขายเป็นชุดครบ แจ้งชัดว่ามีอะไรบ้าง

## ปัจจัยที่ทำให้ราคาลด

- การ์ดจอรุ่นเก่า / อาการจอดำ / artifact
- ประวัติขุดเหมืองหนัก (ต้องแจ้ง)
- PSU ต่ำหรือเสียงดังผิดปกติ
- เปิดไม่ติด รีสตาร์ทเอง
- ขาดชิ้นสำคัญ (ไม่มี RAM/GPU)
- เคส/เมนบอร์ดโดนน้ำ

## ก่อนขายควรเช็กอะไร

1. ถ่ายภาพสเปกจาก CPU-Z + GPU-Z
2. เปิดเคสถ่ายรูปภายใน (สาย/ฝุ่น/รอยน้ำ)
3. ทดสอบเกมหรือ Heaven/FurMark สั้น ๆ (ถ้าทำได้)
4. แจ้ง PSU รุ่นและวัตต์
5. ลบข้อมูลและรีเซ็ต Windows (เมื่อตกลงขาย)
