**คำตอบสั้น:** คอมเก่าไม่มีการ์ดจอ**อาจยังมีมูลค่า**ในบางกรณี — ขึ้นอยู่กับรุ่นย่อย CPU RAM บอร์ด สภาพเปิดติด และราคาตลาด ณ วันที่ประเมิน ไม่มีราคาเดียวสำหรับทุกเครื่อง

## ราคาขึ้นอยู่กับอะไร

เครื่องไม่มีการ์ดจอแยกอาจยังใช้ **จอ onboard** (ถ้า CPU รองรับ) หรือขายเป็น **ชิ้นส่วน** (CPU, RAM, SSD, PSU) ถ้าตลาดยังรับ

ราคาขึ้นกับว่าเปิดติดหรือไม่ เมนบอร์ดรุ่นไหน RAM มีเท่าไร และเครื่องเก่าแค่ไหน — ดู [รับซื้อคอม](/รับซื้อคอม/) และ [ราคากลางรับซื้อ](/ราคากลางรับซื้อ/)

## ปัจจัยที่ทำให้ขายได้ราคาดี

- CPU รุ่นที่ยังมีคนหา (แม้เครื่องเก่า)
- RAM DDR4/DDR5 ที่ยังใช้ได้
- SSD ยังดี
- เมนบอร์ด socket ยังมีอุปกรณ์รองรับ
- เปิดติด ไม่มีรหัส BIOS ล็อก
- PSU ยังใช้ได้
- ไม่โดนน้ำ ไม่มีกลิ่นไหม้

## ปัจจัยที่ทำให้ราคาลด

- เครื่องเก่ามาก ตลาดไม่รับทั้งเครื่อง
- เปิดไม่ติด ไม่ทราบสาเหตุ
- เมนบอร์ดเสีย หรือ capacitor บวม
- HDD ช้า/เสีย
- ไม่มี PSU หรือ PSU เสีย
- ขายไม่ครบชิ้นสำคัญ

## ก่อนขายควรเช็กอะไร

- ลองเปิดด้วยจอ onboard (ถ้ามี) หรือการ์ดจอชั่วคราว
- ถ่ายภาพสเปก CPU/RAM จาก BIOS หรือ Windows
- ถ่ายรูปเมนบอร์ดและ capacitor
- แจ้งอายุเครื่องโดยประมาณ
- ลบข้อมูลก่อนขาย (ถ้าเปิดได้)
