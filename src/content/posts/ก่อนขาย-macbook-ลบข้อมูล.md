**คำตอบสั้น:** ก่อนขาย MacBook ควร**สำรองข้อมูล → ออกจาก Apple ID → ปิด Find My → Erase Mac** (หรือลบผู้ใช้ตามเวอร์ชัน macOS) เมื่อคุณเป็นเจ้าของและรู้รหัสบัญชี

## เรื่องนี้สำคัญอย่างไร

MacBook เก็บเอกสาร รูป โปรเจกต์ และ Keychain หากยังติด Apple ID ผู้ซื้อต่อเปิดใช้ไม่ได้ และคุณอาจเสียข้อมูลส่วนตัว

ร้านรับซื้อที่โปร่งใสจะถามเรื่อง Activation Lock — อ่าน [ความน่าเชื่อถือ](/ความน่าเชื่อถือ/) และ [รับซื้อแมคบุ๊ค](/รับซื้อแมคบุ๊ค/)

## สิ่งที่ควรทำก่อนขาย

1. สำรองด้วย Time Machine หรือ iCloud
2. Sign Out จาก Apple ID (System Settings → ชื่อ → Sign Out)
3. ปิด Find My Mac
4. **Erase All Content and Settings** (macOS Ventura ขึ้นไป) หรือลบผู้ใช้ + ติดตั้งใหม่ตามรุ่น
5. ออกจาก iCloud Keychain / ลบ Touch ID ถ้าระบบถาม
6. แจ้งร้านสเปกและว่าปลดล็อกแล้ว

## สิ่งที่ไม่ควรทำ

- ลบเฉพาะไฟล์ใน Desktop แล้วขาย
- ขายเครื่องบริษัทโดยไม่ปลด MDM
- ใช้เครื่องมือปลด Activation Lock ที่ไม่ชอบด้วยกฎ
- รีเซ็ตโดยไม่สำรอง (ถ้ายังต้องการข้อมูล)
- ปล่อยให้ร้าน “ช่วยลบ” โดยไม่ยืนยันตัวตน

## กรณีที่ร้านต้องตรวจเพิ่ม

- เปิดเครื่องแล้วขอรหัส Activation Lock
- FileVault เปิดอยู่ — ต้องปิดหรือให้รหัสตามขั้นตอนที่ถูกต้อง
- เครื่องมีโปรไฟล์ MDM
- ลืมรหัสผู้ใช้ macOS แต่ยังติด Apple ID

## ขั้นตอนที่ WE BUY แนะนำ

1. ส่งภาพ About และสภาพผ่าน Line ([เช็กราคาก่อนขาย](/เช็กราคาก่อนขาย/))
2. ยืนยันเป็นเจ้าของ จะ Sign Out ก่อนส่งมอบ
3. ดูปัจจัยราคาแบบไม่ใส่ตัวเลขมั่วที่ [ราคากลางรับซื้อ](/ราคากลางรับซื้อ/)
4. Erase Mac เมื่อใกล้ส่งมอบ ให้ตรวจว่าไม่ติดล็อก
5. ราคาสุดท้ายยืนยันหลังตรวจเครื่อง

### ลบไฟล์อย่างเดียวพอไหม
