**คำตอบสั้น:** โน๊ตบุ๊คเกมมิ่งมือสอง**ไม่มีราคาเดียว** — ขึ้นอยู่กับรุ่นย่อย ความจุ สภาพ อุปกรณ์ ประกัน และราคาตลาด ณ วันที่ประเมิน โดยเฉพาะ **รุ่นการ์ดจอ** และสภาพระบบระบายความร้อน

## ราคาขึ้นอยู่กับอะไร

เกมมิ่งประเมินจาก **GPU** เป็นหลัก ตามด้วย CPU รุ่น RAM SSD จอ (Hz/ขนาด) และว่าเคยอัปเกรดหรือซ่อมอะไหล่หรือไม่

โน๊ตบุ๊คเกมมิ่งสองเครื่องที่ดูคล้ายกันอาจราคาต่างกันถ้าการ์ดจอคนละรุ่น — ดู [รับซื้อโน๊ตบุ๊ค](/รับซื้อโน๊ตบุ๊ค/) และ [ราคากลางรับซื้อ](/ราคากลางรับซื้อ/)

## ปัจจัยที่ทำให้ขายได้ราคาดี

- การ์ดจอรุ่นที่ตลาดยังเล่นเกมใหม่ได้ (ตามช่วง)
- CPU ไม่ bottleneck การ์ดจอมาก
- RAM 16GB+ SSD NVMe ความจุพอใช้
- จอไม่เสีย ไม่มี dead pixel
- ระบบระบายดี ไม่ร้อนจนปิดเอง
- ตัวเครื่องไม่บวม ไม่โดนน้ำ
- อแดปเตอร์วัตต์พอ (แจ้งรุ่น)

## ปัจจัยที่ทำให้ราคาลด

- การ์ดจอรุ่นเก่า หรืออาการ artifact/จอดำ
- แบตเสื่อม บวม ชาร์จไม่เข้า
- พัดลมดัง ร้อน หรือเคยเทอร์มอลหลุด
- จอแตก คีย์บอร์ด RGB เสีย (ถ้ามี)
- เปิดไม่ติด หรือ BIOS ล็อก
- ตำหนิหนัก โดนน้ำ

## ก่อนขายควรเช็กอะไร

- รัน GPU-Z / Task Manager ถ่ายภาพ CPU, GPU, RAM
- ทดสอบเกมสั้น ๆ หรือ stress เบา ๆ ดูอุณหภูมิ
- เช็กพัดลมและเสียงผิดปกติ
- ถ่ายรูปตัวเครื่องด้านล่าง (รอยบวม)
- ลบบัญชีและรีเซ็ตเมื่อตกลงขาย
