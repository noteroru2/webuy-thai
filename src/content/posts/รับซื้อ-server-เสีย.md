**รับซื้อ Server เสีย** แม้เครื่องจะเปิดไม่ติดหรือมีอาการที่ดูซ่อมไม่คุ้ม ยังมีมูลค่าในฐานะอะไหล่หรือซาก ชิ้นส่วนที่ยังดีอย่าง CPU, RAM, HDD, Power Supply ยังมีตลาดรองรับ

## Server เสียแบบไหนยังมีมูลค่า

- **Power Supply เสีย** เฉพาะ PSU ตัวเดียว ชิ้นส่วนอื่นยังดี → ราคาดี
- **Board เสีย** แต่ CPU และ RAM ยังดี → ประเมินแยกชิ้น
- **ไฟสัญญาณดับ** หรือค้างหน้า POST → ยังประเมินได้
- **เครื่องเปิดไม่ติดเลย** → ประเมินเป็นซาก ราคาขึ้นกับอะไหล่ที่เหลือ
- **HDD เสียทั้งชุด** → โครงเครื่อง CPU RAM ยังมีค่า

## ข้อมูลที่ควรส่งมาก่อน

1. ยี่ห้อและรุ่น เช่น Dell PowerEdge R730
2. อาการที่พบ
3. สเปกที่รู้ (CPU รุ่น RAM ความจุ)
4. รูปถ่ายหน้าเครื่องและ Label สเปก

## สรุป

Server เสียยังมีมูลค่า ส่งข้อมูลมาเพื่อรับช่วงราคาเบื้องต้นก่อนนัดได้เลยครับ
